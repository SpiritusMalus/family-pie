Установка на Windows и Mac

Windows 10 версии 2004 и новее: запустите скачанный файл .exe. Mac: откройте DMG и перенесите Sufler в «Программы». Установщики пока без цифровой подписи, поэтому система может попросить подтвердить открытие. Для Mac есть инструкция Apple.

При желании сверьте контрольные суммы перед запуском. Настройки сохраняются в вашем профиле при обновлении.

Получите ключ и начните

01

Получите ключ Deepgram

Открыть Deepgram →

  1. Зарегистрируйтесь и выберите проект.
  2. Откройте Settings → API Keys → Create a New API Key.
  3. Назовите ключ «Sufler» и сразу скопируйте его.

Для новых аккаунтов Deepgram предлагает $200 стартового кредита.

02

Вставьте ключ в Sufler

В Sufler откройте ⚙ → «Deepgram · речь», вставьте ключ и нажмите «Проверить подключение». Проверьте отметки «Deepgram» и «Ответы Sufler».

03

Нажмите «Начать»

Прослушивание начнётся только после нажатия. На Windows выберите системный звук; на Mac для голоса собеседника настройте BlackHole.

Как настроить звук на Mac
  1. Установите BlackHole 2ch.
  2. В «Настройке Audio-MIDI» создайте устройство с несколькими выходами: BlackHole и ваши наушники. Выберите его системным выходом. Пошаговая схема.
  3. В Sufler для голоса собеседника выберите «Микрофона или виртуального кабеля» → BlackHole 2ch.

Помощь с настройкой

Как проверить окно перед демонстрацией?

На Windows 10 версии 2004 и новее включите «Прятать от захвата», затем нажмите «Проверить, видно ли окно при захвате» и посмотрите превью. Результат зависит от программы и способа демонстрации.

На Mac тоже проверьте превью перед звонком. Окно можно спрятать клавишами Ctrl+Shift+Space или читать ответы на телефоне. Если звук или снимки экрана недоступны, проверьте разрешения macOS в настройках Sufler и перезапустите приложение.

Есть текст, но нет ответа. Что проверить?

Нажмите «Проверить подключение» и проверьте переключатель «Отвечать сам». Для ручного ответа используйте Ctrl+Shift+A. Если сервис ответов недоступен, попробуйте позже или напишите в поддержку.

Не слышно собеседника. Что проверить?

На Windows выберите системный звук. На Mac проверьте BlackHole и устройство с несколькими выходами. Обычный микрофон не услышит голос в наушниках.

Куда отправляются звук, текст и снимки?

Звук идёт напрямую в Deepgram. Распознанный текст и снимок экрана после вашей команды проходят через сервер Sufler в OpenRouter для ответа. Звук и ключ Deepgram туда не отправляются. Подробнее о данных.

Если нужна помощь, напишите на support@family-pie.ru. Ключ Deepgram и запись разговора для этого не нужны.

Остальные настройки
Ответы и язык

Модели ответов уже выбраны Sufler. Язык определяется автоматически; при желании выберите русский или английский. «Отвечать сам» запрашивает подсказку после реплики; для ручного ответа есть Ctrl+Shift+A.

«Забегать вперёд» запрашивает ответ до конца фразы. «Усиленный разбор» помогает отличать вопрос от подводки, иногда ценой дополнительного запроса. Для начала оставьте значения по умолчанию.

Распознавание и паузы

Для первого разговора оставьте модель STT nova-3, язык multi, endpointing 300 мс и конец фразы 1000 мс. Если весь разговор на одном языке, можно выбрать ru или en-US. Эти настройки влияют на момент распознавания фразы и появления подсказки.

Горячие клавиши

Начать или остановить прослушивание: Ctrl+Shift+M. Ответить на последнюю реплику: Ctrl+Shift+A. Выделить область экрана: Ctrl+Shift+D. Разобрать весь экран: Ctrl+Shift+S. Оборвать ответ: Ctrl+Shift+X.

Показать или скрыть окно: Ctrl+Shift+Space. Включить сквозные клики: Ctrl+Shift+C. Переключить рабочий режим окна: Ctrl+Shift+R. Закрыть Sufler: Ctrl+Shift+Q. Все сочетания можно изменить в настройках.
