Lumen + REST

Перерывы и настройки экрана для времени за компьютером.

macOS: Swift / SwiftUI / AppKit · Windows / Linux: Python / PySide6

Зачем мне это приложение

Я много времени провожу за компьютером. Хочу делать перерывы на разминку и отдых для глаз. Lumen + REST соединяет таймер перерывов с настройками яркости и теплоты экрана.

Перерыв начинается с согласия

После рабочего интервала появляется напоминание. Оно предлагает начать перерыв или остановить таймер. Экран отдыха не перекрывает рабочие окна, пока пользователь не согласится.

Во время отдыха можно нажать Esc и вернуться к работе. Есть пауза и продолжение; в версии для Mac отсчёт рабочего времени ждёт после минуты без активности и не считает сон компьютера работой.

Настройки должны возвращаться

В версии для macOS яркость и теплота меняются программно через цветовые таблицы. Исходные таблицы сохраняются перед включением режима и восстанавливаются при выключении, выходе и сне.

Это не регулировка аппаратной подсветки. Внешние, HDR и DisplayLink-дисплеи требуют отдельной проверки; на Wayland цветом управляет системный «Ночной свет», а таймер продолжает работать.

Разные системы — разные интеграции

На Mac используются SwiftUI, AppKit и CoreGraphics. Windows и Linux имеют отдельную оболочку на Python и PySide6. Настройки сохраняются локально; для таймера и напоминаний не нужен аккаунт.
