Lumen + REST

A break timer with screen brightness and color controls.

macOS: Swift / SwiftUI / AppKit · Windows / Linux: Python / PySide6

How I use Lumen + REST

I wanted Lumen + REST to remind me to get up and stretch during the working day. I installed it on my desktop computer to help me take breaks. Its display controls also let me dim the screen and make its colors warmer.

How the break timer works

At the end of a work interval, a reminder offers to start a break or stop the timer. The rest screen opens only after the user accepts the break.

Pressing Escape during a break returns to work. The timer can also be paused and resumed. On macOS, it stops counting work time after a minute of inactivity and while the computer is asleep.

Brightness and screen color

On macOS, the app adjusts brightness and color temperature through display color tables. It saves the original tables before applying a change and restores them when the mode is switched off, the app quits or the computer goes to sleep.

The app changes the displayed image through software. The monitor’s backlight setting stays the same. External monitors, HDR and DisplayLink displays need separate testing. On Wayland, display color is handled by the system’s Night Light setting, and the break timer remains available.

macOS, Windows and Linux versions

The macOS app uses SwiftUI, AppKit and CoreGraphics. The Windows and Linux version is written in Python with PySide6. Settings are stored locally. The timer and reminders work without an account.
