Driftora

Хочу привести себя в форму. Каждый день записываю в Driftora, что съел. Там же отмечаю тренировки и ходьбу.

Мне нужен был учёт калорий с голосовым вводом еды. Подходящего приложения, которому я доверял бы, не нашёл. Сделал Driftora сам: интерфейс, сервер и расчёты.

Как устроена Driftora

React Native / Expo · TypeScript · Express · SQLite

Lumen + REST

Я поставил Lumen + REST на свой компьютер, чтобы делать перерывы и давать глазам отдых. В приложении можно сделать оттенок экрана теплее.

Таймер предлагает остановиться. Экран отдыха появляется после согласия; можно вернуться к работе в любой момент.

Как устроен Lumen + REST

macOS: Swift / SwiftUI · Windows и Linux: Python / PySide6
