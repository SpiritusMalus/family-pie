# Product screen provenance

These JPEGs capture the products' actual interface code with demonstration data.
They are neither generated illustrations nor screenshots of customer records.

- `vpn-*`: Family VPN cabinet from Family Pie source `85cf0eb`, rendered against
  the existing isolated in-memory API. Android/Windows instructions and support
  are real product screens. The displayed account is a fixture without a paid
  subscription, personal connection link or payment.
- `sufler-*`: Sufler's unchanged React renderer from WorkTracker `b84558d`,
  rendered locally with an isolated bridge and prepared interview question and
  talking points. These are interface demonstrations, not a recording of a live
  interview, real speech recognition or a model response. No real API key,
  microphone, call, model request or owner's app profile was used.

The interface language is Russian; both website languages say so explicitly.
Screens open at their original dimensions from the homepage. The homepage changes still frames only after the visitor selects a labelled screen.
The before-listening Sufler capture is retained as an existing public asset; the
current homepage compares only the interviewer question and talking points.
Native application, paid-flow and physical VPN acceptance are outside this change.
