# family-pie.ru — Промт для Claude Code

Скопируй всё, что ниже разделителя, в Claude Code как стартовое задание. В этой же папке (`handoff/`) лежат материалы, на которые ссылается промт: дизайн-референс и юридические тексты.

---

## Задача

Собери и задеплой статический сайт **family-pie.ru** — зонтичную (витринную) страницу независимой студии приложений family-pie. На странице представлены два продукта; по клику каждый раскрывается в «визитку» со ссылками на App Store / Google Play и юридическими документами. Студия планирует добавлять новые продукты (до 3–6), поэтому структура должна легко расширяться.

Это маркетинговый сайт, не приложение. Никакого бэкенда, БД или авторизации. Чистый статический фронтенд, разворачиваемый на любом статическом хостинге (Netlify / Vercel / GitHub Pages / nginx).

## Стек

- **Vanilla HTML + CSS + минимум JS** (без фреймворка) ИЛИ **Astro**, если хочешь компонентность и удобную расширяемость каталога продуктов. Предпочтительно Astro — он даёт статический вывод, удобные «коллекции» для продуктов и для юр-документов из markdown.
- Без сборки тяжёлых зависимостей. Шрифты — Google Fonts (Space Grotesk, Space Mono, Manrope).
- Деплой статикой. Добавь `robots.txt`, `sitemap.xml`, корректные `<title>`/`og:`-метатеги.

## Дизайн (строго следовать референсу)

Визуальный эталон — файл **`Family Pie.dc.html`** (открой в браузере). Это направление «бумага / редакторский». Воспроизведи его 1:1: цвета, типографику, отступы, поведение. Ниже — спецификация, но если есть расхождение, **источник истины — этот HTML**.

### Палитра
- Фон бумаги: `#F4F1EA`
- Чернила (текст): `#1B1A17`
- Вторичный текст: `#6b655c`, приглушённый: `#8d8678`, ещё светлее: `#a89f8d`
- Линии-разделители: `#E4DDCE`
- Акцент Relo Dojo (зелёный): `#0E8A30` (вторичный золотой `#E3A52C`)
- Акцент Health Routine (коралловый): `#D8513A`
- Бейдж-фон зелёный `#e9f5ec`, коралловый `#fbeae5`

### Типографика
- Заголовки: **Space Grotesk** 700, отрицательный letter-spacing (`-.02em`), `text-wrap: balance`
- Текст: **Manrope** 400–600
- Подписи/моно-метки (eyebrow, номера, лейблы): **Space Mono**, uppercase, `letter-spacing: .14em`
- H1 героя ~64px, названия продуктов ~34px, текст 16–19px. Минимум 15px.

### Знак family-pie
Простой геометрический «пирог из секторов»: круг, делённый на 6 секторов тонкими линиями цвета фона. Два сектора — акцентные (зелёный `#0E8A30` и коралловый `#D8513A`), остальные — нейтральные тёплые тона (`#E3A52C`, `#E8E1D3`, `#E2DACB`, `#EDE7DA`). SVG уже есть в референсе — переиспользуй. По наведению знак плавно поворачивается на 180°. При загрузке секторы появляются по очереди (stagger-анимация).

### Структура страницы
1. **Липкий навбар** (blur-фон): знак + «family-pie» слева; справа — якорь «Продукты» и переключатель языка RU/EN (пилюля).
2. **Герой**: моно-eyebrow «Студия приложений», крупный H1, подзаголовок-абзац.
3. **Список продуктов** — нумерованные строки (`01`, `02`, …), каждая: акцентная иконка-квадрат, название, краткий тег, и справа лейбл «открыть +» / «— свернуть».
   - Клик раскрывает строку (анимация высоты через `grid-template-rows: 0fr → 1fr` + плавная opacity).
   - Внутри: слева описание + чипы-фичи; справа блок «Скачать» с кнопками App Store / Google Play (сейчас в статусе **«Скоро»**) и ссылками на Оферту + Конфиденциальность.
   - hover на строке слегка подсвечивает фон (`#EFEBE0`).
4. **Плейсхолдер дорожной карты**: пунктирная строка «Здесь появятся новые продукты».
5. **Подвал**: копирайт + контактный email.

### Взаимодействия (все уже реализованы в референсе — перенеси)
- Плавное раскрытие/сворытие карточек.
- Hover-подсветка строк и подъём кнопок сторов.
- Появление блоков при скролле (IntersectionObserver, fade + translateY).
- Анимация знака-пирога (поворот по hover, stagger секторов на загрузке).
- Кнопки сторов в статусе «Скоро» показывают тост-уведомление «сообщим, когда выйдет» (в проде — заменить на подписку/ссылку, см. ниже).

### Двуязычность
RU по умолчанию + переключатель EN. Переключатель меняет язык всего сайта. В референсе словарь зашит в JS — структуру повтори (или в Astro — через i18n-роутинг `/` и `/en/`).

## Продукты

### 1. Relo Dojo — Английский для IT-релокации (зелёный)
Геймифицированная практика английского для айтишников, переезжающих за рубеж: 5 минут в день, упражнения под роль и цели, XP, стрики, пояса от белого до чёрного, подготовка к интервью. Английский интерфейс приложения. Маркетинговые тексты и тон — см. `content/relo-dojo/STORE_LISTING.md` и `content/relo-dojo/BRAND_ASSETS.md`.
- Иконка: марка-тории/«крыша додзё» (треугольник + золотая перекладина) — SVG в референсе.
- Юр-документы: `content/relo-dojo/TERMS_OF_USE.en.md`, `content/relo-dojo/PRIVACY_POLICY.en.md` (оригинал — английский).

### 2. Health Routine — Забота о себе каждый день (коралловый)
Спокойный дневник самочувствия: настроение и мысли (КПТ), вес, шаги, питание. Без рекламы и регистрации, сквозное шифрование, данные на устройстве. Русский интерфейс.
- Иконка: сердце-контур — SVG в референсе.
- Юр-документы: `content/health-routine/TERMS_OF_USE.ru.md`, `content/health-routine/PRIVACY_POLICY.ru.md` (оригинал — русский).
- У Health Routine уже есть готовая юр-страница (`web-legal/legal.html` в репозитории HealthRoutine) — можно переиспользовать её содержимое/верстку или привести к единому стилю family-pie.

## Юридические страницы (важно)

Сделай для **каждого** продукта страницу с двумя вкладками — **Оферта (Terms)** и **Конфиденциальность (Privacy)** — в едином «бумажном» стиле family-pie, с акцентным цветом своего продукта, липким топбаром-табами и оглавлением (TOC) сбоку со скролл-спай. Скелет такой страницы я уже спроектировал — повтори его (sticky tabs + sticky TOC + секции с моно-нумерацией).

**Двуязычность юр-страниц:** нужны RU и EN версии обоих документов для обоих продуктов.
- Relo Dojo: оригинал английский → нужен русский перевод.
- Health Routine: оригинал русский → нужен английский перевод.
- Сделай аккуратный смысловой перевод, **сохраняя все плейсхолдеры `[INSERT ...]` / `[ДАТА ...]` как есть** — их заполняет владелец.

⚠️ **Юридическая оговорка:** исходники помечены как черновики, требующие проверки юристом перед публикацией. Не выдавай перевод за заверенный документ. Сохрани вводный disclaimer на каждой странице.

### Незаполненные поля (передай владельцу как TODO)
Во всех документах есть плейсхолдеры, которые должен заполнить владелец перед публикацией:
- `[INSERT LEGAL NAME / ИП]` — юрлицо/ИП оператора
- `[INSERT CONTACT EMAIL]` — контактный email (предложен `hello@family-pie.ru`)
- `[INSERT DATE / ДАТА ВСТУПЛЕНИЯ]` — дата вступления в силу
- `[INSERT JURISDICTION / VENUE]` — применимое право и подсудность
- `[INSERT POSTAL ADDRESS ...]` — почтовый адрес, если требует стор/рынок
- Relo Dojo: возрастной порог `[13 / 16]` — выбрать по рынкам

## Ссылки на сторы

Сейчас оба приложения **не опубликованы** — кнопки App Store / Google Play в статусе «Скоро». Сделай их легко заменяемыми: вынеси URL'ы сторов в конфиг (в Astro — в данные продукта; в vanilla — в объект конфигурации вверху JS). Когда появятся ссылки:
- статус `soon` → `live`, кнопка становится реальной ссылкой;
- (опционально) на время «Скоро» — поле email для подписки «сообщить о релизе» через любой no-code сервис (Formspree/Buttondown) — обсуди с владельцем, по умолчанию просто disabled-кнопка с тостом.

## Расширяемость каталога

Каталог продуктов держи как **данные**, не как хардкод-разметку. Добавление нового продукта = одна запись (id, название, тег, описание RU/EN, акцентный цвет, иконка-SVG, ссылки сторов, пути к 4 юр-файлам) + 4 markdown-файла. Сетка/список и юр-страницы генерируются из этих данных. Это ключевое требование — студия будет расти.

## Критерии приёмки
- [ ] Главная визуально совпадает с `Family Pie.dc.html`, все анимации на месте.
- [ ] RU/EN переключается на всех страницах.
- [ ] У каждого продукта — раскрывающаяся визитка + 2 рабочих юр-страницы (Оферта/Конфиденциальность) на 2 языках.
- [ ] Все плейсхолдеры `[INSERT ...]` сохранены и собраны в один TODO-список для владельца (`README` или `TODO.md`).
- [ ] Адаптив: телефон / планшет / десктоп. На мобильном TOC юр-страниц скрывается.
- [ ] Lighthouse: доступность и SEO ≥ 90, корректные метатеги и `lang`.
- [ ] Новый продукт добавляется правкой данных + markdown, без трогания вёрстки.
